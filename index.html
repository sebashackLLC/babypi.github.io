Enhance your gameplay with scripts.

The baby.tech LUA framework allows you to build custom indicators, control angles for anti-aim, and design highly personalized widgets with direct game loop hooks.

Getting Started

Place your script in the baby/lua/ directory inside your Team Fortress 2 folder (e.g. baby/lua/test.lua). Open the cheat menu, navigate to the Configs → Lua tab, and toggle your script to load it.

Event Loop Hooks

All script interactions are driven by events. Use client.register_callback to subscribe to paint and create_move ticks.

client.register_callback("paint", function()
    -- Render operations here
end)

client namespace

Utility functions for interacting with the cheat's core, logging, input events, and user settings.

client.log (string message)

Outputs a custom message directly to the game developer console with the baby.tech prefix.

client.log("Hello from baby.tech LUA!")
client.register_callback (string event, function callback)

Hooks a LUA function to be executed during specific game events.

Event Description
"paint" Runs every screen render frame. Used for drawing custom indicators, panels, or esp.
"create_move" Runs on local movement packet generation. Used for anti-aim, speed adjustments, and command modification.
client.key_down (int virtual_key)

Returns whether the specified virtual key code is currently held down.

if client.key_down(1) then -- 1 is Left Mouse Button
    client.log("LBUTTON held down!")
end
client.key_pressed (int virtual_key)

Returns true only on the initial frame a key is pressed down.

client.is_menu_open ()

Returns true if the baby.tech UI menu is currently open on screen.

client.mouse_pos ()

Returns two integers representing the current cursor coordinates (x, y) on the screen.

local mx, my = client.mouse_pos()
client.menu_accent ()

Returns the current RGB values of the active UI accent color selected by the user (r, g, b).

local ar, ag, ab = client.menu_accent()
client.get_bind_info (string bind_name)

Returns a table with keybind info from C++ config: { active = bool, key_name = string, mode = string, key = int }.

local info = client.get_bind_info("aimbot")
if info then
    client.log("Aimbot bind is " .. info.key_name .. " and state is " .. tostring(info.active))
end

draw namespace

API functions to draw custom text, vector shapes, bounding boxes, and execute custom premium animations.

draw.text (string text, int x, int y, int r, int g, int b, int a, [string font])

Draws text to the screen. Supported fonts: "menu", "esp", "esp_small", "indicator", "splash".

draw.rect (int x, int y, int w, int h, int r, int g, int b, int a)

Draws a solid filled rectangle.

draw.outlined_rect (int x, int y, int w, int h, int r, int g, int b, int a)

Draws a single-pixel outline border rectangle.

draw.filled_rounded_rect (int x, int y, int w, int h, int radius, int r, int g, int b, int a)

Draws a perfectly anti-aliased filled rectangle with rounded corners using native engine polygon rendering.

draw.outlined_rounded_rect (int x, int y, int w, int h, int radius, int r, int g, int b, int a)

Draws a perfectly anti-aliased outline border rectangle with rounded corners.

draw.head_box (bool fake, int r, int g, int b, int a)

Renders a 3D bounding box around the local player's head. Set fake to true to draw the desynchronized fake anti-aim head, or false to draw the real head position.

draw.line (int x1, int y1, int x2, int y2, int r, int g, int b, int a)

Draws a line from coordinates (x1, y1) to (x2, y2).

draw.circle (int x, int y, int radius, int segments, int r, int g, int b, int a)

Draws an unfilled segment circle.

draw.screen_size ()

Returns the current width and height of the game viewport window (w, h).

draw.text_size (string text, string font)

Calculates and returns the bounding width and height of the text string for the chosen font type (width, height). Crucial for right-aligning UI elements.

draw.animated_bar (string id, int x, int y, int w, int h, float target_fraction, int r, int g, int b, int a, [string anim_type], [float speed])

Draws a sliding progress bar with built-in interpolation animations on the C++ side. Extremely smooth performance.

Animation Type Description
"spring" Default. Uses a custom mass-spring physics engine with critical damping (0.7) for a bouncy Apple-style slider feedback.
"lerp" Traditional exponential sliding easing animation.
"linear" Constant speed slide.
draw.animated_text (string id, string text, int x, int y, int r, int g, int b, int a, [string anim_type], [float speed], [string font])

Executes animations on text directly in the rendering pipeline for maximum performance.

Animation Type Description
"pulse" Pulsates the alpha transparency of the text using a smooth sine wave.
"rainbow" Generates a dynamic RGB cycling color effect across the text.
"shake" Adds a glitchy retro shake to the text coordinates.
"wave" Vertically floats the text up and down.

engine namespace

Retrieve game-state telemetry such as active connections, angle lists, doubletap metrics, and weapon crithack predictions.

engine.is_in_game ()

Returns true if the local player is currently loaded into a game server map.

engine.fake_angles ()

Returns the current fake angles (pitch, yaw, roll) being dispatched to the game server.

engine.real_angles ()

Returns the real client viewangles (pitch, yaw, roll) calculated by the game simulation.

engine.doubletap_info ()

Returns doubletap telemetry: (ticks_accumulated, max_ticks, is_recharging).

engine.crit_info ()

Returns crithack telemetry details: (is_crit_allowed_by_server, is_boosted, is_force_crit_active).

cmd namespace

Write, read, and override command values inside the create_move event loop.

Warning: cmd functions are only functional inside create_move callbacks. Accessing them from draw or paint will fail.
cmd.get_viewangles ()

Returns the original user-input angles (pitch, yaw, roll).

cmd.set_viewangles (float pitch, float yaw, float roll)

Sets new command viewangles. This is used to implement custom anti-aims, spinbots, or trigger rotations.

cmd.get_sendpacket ()

Returns whether the current command packet is flagged to be sent to the server (true) or choked (false).

cmd.set_sendpacket (bool send)

Chokes or dispatches the current packet. Alternating this creates client-side desynchronization (fake lag / fake body angles).

menu namespace

Create custom checkboxes, sliders, and dropdown menus dynamically inside the cheat's default GUI LUA tab.

menu.add_checkbox (string label, bool default_value)

Registers a checkbox to the UI. Returns the current menu state (true/false) on every query.

local draw_panel = menu.add_checkbox("Show Indicator Panel", true)
menu.add_slider_int (string label, int min, int max, int default_value)

Registers an integer slider. Returns the selected value integer.

local offset = menu.add_slider_int("Yaw Offset", -180, 180, 90)
menu.add_select (string label, table options, int default_index)

Registers a combobox dropdown select field. Indexing starts at 1.

local mode = menu.add_select("Jitter Mode", {"None", "Standard", "Random"}, 1)

localplayer namespace

Check active local user data parameters.

localplayer.alive ()

Returns true if the local client player is currently alive in game.

localplayer.health ()

Returns the current health points of the local player.
